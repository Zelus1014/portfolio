# Redgie Y. Blanco — Personal Portfolio

A modern, clean, and responsive personal portfolio website built for a Computer Science student.

## Technologies Used

- **HTML5** — Structure and semantic markup
- **CSS3** — Styling, layout, animations, and responsive design
- **JavaScript** — Navigation interactivity, scroll effects, and active link highlighting
- **Font Awesome 6** — Professional icons
- **Google Fonts (Inter)** — Typography

## Features

- Single-page layout with smooth scrolling navigation
- Hero/Home section with profile image and introduction
- About Me section with personal background
- Skills section organized by categories (no fake percentages)
- Projects section with academic project cards
- Contact section with email and social links
- Responsive design (desktop, tablet, mobile)
- Subtle hover effects and scroll-triggered animations
- Mobile-friendly hamburger navigation

## How to Run Locally

1. **Download or clone** this repository to your computer.
2. **Open the folder** in VS Code or any code editor.
3. **Open `index.html`** in your browser — just double-click the file, or use a live server extension in VS Code (recommended for the best experience).

### Using VS Code Live Server (Recommended)

1. Install the **Live Server** extension by Ritwick Dey.
2. Right-click `index.html` and select **"Open with Live Server"**.
3. The website will open in your browser and auto-reload on changes.
